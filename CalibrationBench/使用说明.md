## 1. 程序组成与运行

| 程序 | 说明 |
|------|------|
| `CalibrationBench.UI.exe` | 界面程序（操作入口） |
| `CalibrationEngine.exe` | 无界面解算引擎（被界面调用，需与界面同目录） |

运行：双击 `CalibrationBench.UI.exe`（需 .NET Framework 4.7.2，Win10/11 自带；引擎须与界面同目录）。

顶部先填写：

- **设备编号**（默认 `AT1`）
- **设备根目录**（成果归档到其下 `device_info/<编号>/`）
- **校准引擎 / 配置文件**（一般自动侦测：引擎=同目录、配置=`设备根\calibration_config.json`）

---

## 2. 校准四步与放行判据

| 步骤 | 内容 | 是否需旋转采集 | 放行判据 |
|------|------|----------------|----------|
| 0A 相机内参 | 棋盘格标定(外部/手动) | 否 | 重投影 RMS < 0.5 px |
| 0B 安装角 δ | 铅垂静止多帧 | 否 | 各次偏差 ≤ 0.05° |
| 0C 航向 ψ_offset | ≥8 方位 | **是** | 残差 < 0.1° |
| 0D 综合验证 | 8 方位 PnP 闭合 | **是** | σ_rot<0.3mm 且 闭合<0.5mm |

> 旋转采集仅 0C/0D 需要，且共用一次多方位采集；0A/0B 不转台。

---

## 3. 数据源：模拟 / 真实

「采集编排」分组有 **数据源** 下拉：

- **模拟(无硬件)**：按已知真值合成数据，用于验证流程、培训、无硬件联调。
- **真实(硬件驱动)**：使用 `Acquisition/Real` 驱动（旋转台串口 + 相机/PnP/IMU）。首次用请先点 **连接自检**（见 §7）。

---

## 4. 操作模式一：自动 step-and-stare（有电动旋转台）

适用：配备电动旋转台，可程序化下发方位并悬停。

流程：

1. 顶部填设备编号/根目录；数据源选 **真实**，填 **旋转台串口**（如 COM3）。
2. 点 **连接自检**，确认内参/旋转台/场景采集均 ✔。
3. 先做 **0A 相机内参**（见 §6）与 **0B 安装角**：
   - 0B：设备铅垂静止，点「采集 0B(静止)」生成 `acquired\0B_input.json`，再点 **Step 0B** 选它执行。
4. 设「方位间隔°/方位数/每方位帧数/稳定秒」→ 点 **采集 0C/0D(多方位)**：
   - 程序自动：逐方位 `旋转下发→悬停稳定→间隔采样多帧→PnP`，生成 `acquired\0C_input.json`、`0D_input.json`。
5. 点 **Step 0C** 选 `0C_input.json` 执行（写 ψ_offset）；再点 **Step 0D** 选 `0D_input.json` 执行（放行）。

---

## 5. 操作模式二：手动挪位采样（无旋转台）

适用：无电动旋转台，操作员人工把悬吊设备转/挪到各方位悬停。

流程：

1. 数据源可选 模拟或 真实（真实=采当前物理位置）。
2. **0B**：设备铅垂静止，点「手动挪位采样」分组的 **追加0B(静止)**（可多次累积），再 **生成0B** → 点 **Step 0B** 执行。
3. **0C/0D**：
   - 人工转到第 1 个方位悬停 → 设「名义方位°」→ 点 **采集本站(0C/0D)**（站数+1）；
   - 转到下一方位，改「名义方位°」，再点 **采集本站**；重复 ≥3 站（推荐 8 站，均匀分布）；
   - 点 **生成0C/0D** → 得到 `acquired\0C_input.json`、`0D_input.json`；
   - 点 **Step 0C**、**Step 0D** 分别执行。
4. **重置会话** 可清空当前手动累积，重新开始。

> 提示：每站取「每方位帧数」帧；站间尽量悬停稳定后再采（满足稳态阈值）。

---

## 6. 操作模式三：手动喂 JSON（离线 / 外部数据）

适用：采集与解算分离，或用外部工具产生输入，仅用引擎解算。

流程：

1. 准备符合契约的输入 JSON（字段见 [数据字典与接口说明.md](数据字典与接口说明.md)）；`samples/` 提供 `0A/0B/0C/0D_input.json` 可直接用。
2. 直接点 **Step 0A/0B/0C/0D** 按钮，选对应输入 JSON 执行。
3. 或命令行：
   ```
   CalibrationEngine.exe --step 0D --input 0D_input.json --output out.json --config calibration_config.json --device-root . --device-id AT1
   ```

Step 0A（相机内参）通常走此模式：用外部棋盘格标定得到内参，填入 `0A_input.json`（或经 `CameraCalibration.exe`），点 **Step 0A** 写入 config。

## 6.5 导入到 dsat 主程序（供测量后处理）

出厂标定完成后，把工装产出的 `calibration_config.json` 导入 dsat：

1. dsat 主界面校准区点 **导入出厂校准 / 现场参数(H·D)** → 选择该 `calibration_config.json` → 校验并写入。
2. 在同一面板录入本测站 **H（相机到地面高度，mm）** 与 **D（磁偏角）**。**H 出厂为 0，必须现场测量录入**，否则后处理偏移为 0。
3. dsat 的 0A/0B 面板已改为只读；如需重标，用本工装重做后重新导入。

> 配置结构扁平、与 dsat 后处理完全兼容，`OffsetCalculator` 直接读取内参/δ/ψ/D/H 计算。
>
> 出厂配置已含**内参/δ/ψ_offset/D**（现场项也在其中）；现场仅需补 **H**，并可按需对 0C 航向/磁标定/D 现场重校（覆盖）。导入面板提供**一键校验完整性**。

---

## 7. 连接自检（真实模式必用）

点 **连接自检**，逐项输出 ✔/✖：

1. **内参**：能否从 `calibration_config.json` 读到（否则先做 0A）。
2. **旋转台**：真实模式下串口能否打开并回 `STAT?`。
3. **场景采集**：实际采一帧（相机+PnP+IMU），成功打印 `offsetPnp / H / θ_img`，失败给出具体驱动缺失原因。

模拟模式应全绿；真实模式据此定位未接入的驱动。

## 8. 成果与存储位置

| 产出 | 路径 |
|------|------|
| 采集输入 | `<设备根>\acquired\0A|0B|0C|0D_input.json` |
| 步骤输出 | `<输入同级>\output\<step>_output.json` |
| 汇总配置 | `<设备根>\calibration_config.json`（0A/0B/0C 合格后写入） |
| 归档 | `<设备根>\device_info\<编号>\<stepdir>\{input,output}\<step>_<时间戳>.json` |

`<stepdir>`：0A→camera_calibration、0B→mounting_calibration、0C→heading_calibration、0D→factory_verification。

---

## 9. 接入真机（集成开发）

三步即可，其余不动（引擎/编排/界面/契约不变）：

1. **相机**：`DelegatingCameraSource(grab,open)` 注入相机 SDK 抓帧；或实现 `IndustrialCameraSource`。
2. **IMU**：`DelegatingImuSource(read,open)` 注入 BWT901BLE 读数；或定义 `USE_WITSDK` 用 `Bwt901ImuSource(Bwt901ble)`。
3. **PnP**：NuGet 装 OpenCvSharp4，定义 `USE_OPENCV` 启用 `OpenCvCharucoPnpSolver`（按物理板改 CharucoBoard 参数）。
4. **旋转台**：`RealRotaryStage` 串口协议 `MOVE/LOCK/STAT?`，不同则改命令帧。

接线模板见 [Acquisition/Real/RealWiringSample.cs](CalibrationBench.UI/Acquisition/Real/RealWiringSample.cs)。

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| 日志中文乱码 | 用最新引擎(已设 UTF-8 输出)；确保界面与引擎同目录 |
| 未找到引擎 | 顶部「校准引擎」指到 `CalibrationEngine.exe` |
| 真实场景采集 ✖ | 按自检提示实现相机/IMU/PnP 驱动 |
| 旋转台打不开 | 核对串口号/波特率/协议；无台则用手动模式 |
| 0C/0D 未通过 | 检查方位是否≥3且均匀、稳态是否满足、内参/δ 是否已标 |
