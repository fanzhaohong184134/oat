# 出厂校准工装 — 数据字典与接口说明 V1.0

本文件逐项说明校准**输入/输出每一项数据**、命令行/进程接口、以及**校准输出的最终存储位置**。
配套：[README.md](README.md)、[../校准台研制详细方案设计.md](../校准台研制详细方案设计.md)、[../校准方案（靶标板自定位）.md](../校准方案（靶标板自定位）.md)

---

## 1. 程序组成与解耦关系

| 程序 | 类型 | 职责 |
|------|------|------|
| `CalibrationEngine.exe` | 无界面控制台 | 执行 0A/0B/0C/0D 解算、判据、写配置与归档 |
| `CalibrationBench.UI.exe` | WinForms 界面 | 采集输入、以进程方式调用引擎、展示结果 |

> UI 仅通过**进程命令行**调用引擎，二者与 dsat 主应用/后处理程序**无代码依赖**，独立安装（见 installer）。

---

## 2. 命令行接口（引擎）

```
CalibrationEngine.exe --step 0A|0B|0C|0D --input <in.json> --output <out.json>
                      [--config <calibration_config.json>]
                      [--device-root <DIR>] [--device-id <ID>]
```

| 参数 | 必填 | 说明 |
|------|------|------|
| `--step` | 是 | 校准步骤：0A 内参 / 0B 安装角 / 0C 航向 / 0D 验证 |
| `--input` | 是 | 输入 JSON 文件路径 |
| `--output` | 否 | 输出 JSON 文件路径（不填则仅归档/打印） |
| `--config` | 否 | 汇总配置文件；0A/0B/0C 合格后写入 |
| `--device-root` | 否 | 设备资料根目录（其下建 `device_info/`）用于归档 |
| `--device-id` | 否 | 设备编号（缺省取输入 JSON 的 DeviceId） |
| `--report` | 否 | 仅 0D：出厂校准报告(Markdown)输出路径；省略且提供 device-root/-id 时自动写入 `factory_verification/output/calibration_report_<时间戳>.md` |

**退出码**：`0`=合格；`2`=执行成功但未达判据；`1`=错误。

## 3. 校准输入数据说明（逐项）

### 3.1 Step 0A 相机内参 — 输入 `Step0AInput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| DeviceId | string | - | 设备编号 |
| Intrinsics.Fx / Fy | double | 像素 | 焦距 |
| Intrinsics.Cx / Cy | double | 像素 | 主点 |
| Intrinsics.K1 / K2 | double | - | 径向畸变 |
| Intrinsics.P1 / P2 | double | - | 切向畸变 |
| Intrinsics.ImageWidth / ImageHeight | int | 像素 | 图像尺寸 |
| ReprojRms | double | 像素 | 重投影 RMS；<0 表示未提供 |
| RmsLimitPx | double | 像素 | 合格阈值（默认 0.5） |

### 3.2 Step 0B 安装角 — 输入 `Step0BInput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| DeviceId | string | - | 设备编号 |
| Samples[] | 数组 | - | 稳态多帧样本 |
| Samples[].PitchCamDeg | double | ° | 相机光轴 pitch（PnP，相对世界铅垂） |
| Samples[].RollCamDeg | double | ° | 相机光轴 roll |
| Samples[].ImuAngleYDeg | double | ° | IMU pitch = AngleY |
| Samples[].ImuAngleXDeg | double | ° | IMU roll = AngleX |
| ToleranceDeg | double | ° | 各次偏差合格阈值（默认 0.05） |

### 3.3 Step 0C 航向 — 输入 `Step0CInput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| DeviceId | string | - | 设备编号 |
| AlphaBoardDeg | double | ° | 靶标板 X 轴真方位 α_board |
| MagneticDeclinationDeg | double | ° | 磁偏角 D |
| Samples[] | 数组 | - | ≥8 方位样本（每方位多帧已平均） |
| Samples[].NominalAzimuthDeg | double | ° | 名义方位（仅记录） |
| Samples[].ThetaImgBoardDeg | double | ° | 图像中板 X_B 相对相机 X 轴方位 θ_img |
| Samples[].ImuAngleZDeg | double | ° | IMU 航向 AngleZ（磁北） |
| ToleranceDeg | double | ° | 残差合格阈值（默认 0.1） |

### 3.4 Step 0D 综合验证 — 输入 `Step0DInput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| DeviceId | string | - | 设备编号 |
| Intrinsics | 对象 | - | 相机内参（同 0A 输出） |
| DeltaPitch / DeltaRoll | double | ° | 0B 安装角结果 |
| PsiOffsetDeg | double | ° | 0C 航向结果 |
| MagneticDeclinationDeg | double | ° | 磁偏角 D |
| AlphaBoardDeg | double | ° | 板真方位（磁航向误差诊断用） |
| Frames[] | 数组 | - | 8 方位多帧 |
| Frames[].NominalAzimuthDeg | double | ° | 名义方位（分组键） |
| Frames[].UCorrPx / VCorrPx | double | 像素 | 畸变校正后靶心像素 |
| Frames[].H_mm | double | mm | 相机到板面高度 |
| Frames[].ImuAngleXDeg / YDeg / ZDeg | double | ° | IMU roll/pitch/yaw |
| Frames[].OffsetPnpE_mm / N_mm | double | mm | PnP 真值(ENU) |
| SigmaRotLimit_mm | double | mm | 旋转一致性阈值（默认 0.3） |
| ClosureLimit_mm | double | mm | 各方位闭合阈值（默认 0.5） |
| ClosureMeanLimit_mm | double | mm | 闭合均值阈值（默认 0.3） |

## 4. 校准输出数据说明（逐项）

### 4.1 Step 0A — 输出 `Step0AOutput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| Passed | bool | - | 是否合格 |
| Message | string | - | 结论说明 |
| Intrinsics | 对象 | - | 回传内参 |
| ReprojRms | double | 像素 | 重投影 RMS |

### 4.2 Step 0B — 输出 `Step0BOutput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| Passed | bool | - | 是否合格 |
| Message | string | - | 结论 |
| DeltaPitch / DeltaRoll | double | ° | 安装角稳健均值 |
| MaxDeviationDeg | double | ° | 各次相对均值最大偏差 |
| SampleCount | int | - | 样本数 |

### 4.3 Step 0C — 输出 `Step0COutput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| Passed | bool | - | 是否合格 |
| Message | string | - | 结论 |
| PsiOffsetDeg | double | ° | 圆均值 ψ_offset |
| ResidualDeg | double | ° | 最大残差 |
| PerAzimuth[] | 数组 | - | 各方位 {NominalAzimuthDeg, PsiOffsetDeg, ResidualDeg} |

### 4.4 Step 0D — 输出 `Step0DOutput`

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| Passed | bool | - | 是否放行 |
| Message | string | - | 结论 |
| SigmaRot_mm | double | mm | 旋转一致性散布 |
| ClosureMax_mm | double | mm | 各方位最大闭合偏差 |
| ClosureMean_mm | double | mm | 闭合均值 |
| PredictedErr_mm | double | mm | 计入 δψ=1° 余量的预测最终误差 |
| PerAzimuth[] | 数组 | - | 各方位 {方位, 帧数, OffsetSys(E,N), OffsetPnp(E,N), Closure_mm, MagHeadingErrDeg} |

### 4.5 汇总配置 `calibration_config.json`（CalibrationConfig）

**结构与 dsat 后处理的 `CalibrationConfig` 完全一致（扁平顶层字段），后处理可直接 `CalibrationConfig.Load` 解析计算。** 额外字段 `DeviceId/AlphaBoard/CalibratedAtUtc` 仅供工装留痕，dsat 读取时忽略。

| 字段 | 类型 | 单位 | 来源 |
|------|------|------|------|
| Fx / Fy / Cx / Cy | double | 像素 | 0A |
| K1 / K2 / P1 / P2 | double | - | 0A |
| ImageWidth / ImageHeight | int | 像素 | 0A |
| PsiOffset | double | ° | 0C |
| DeltaPitch / DeltaRoll | double | ° | 0B |
| MagneticDeclination | double | ° | 0C（现场变量，可现场覆盖） |
| **HeightH** | double | mm | **现场测量后填入（出厂为 0）** |
| GThreshold / OmegaThreshold / MinStableFrames | double/int | - | 默认 0.005 / 0.3 / 3 |
| DeviceId / AlphaBoard / CalibratedAtUtc | - | - | 工装留痕（dsat 忽略） |

> ⚠️ **HeightH（相机到地面高度 H）出厂标定不测量**，导入 dsat 后必须在现场测量并录入，否则后处理偏移计算结果为 0。

## 5. 校准输出的最终存储位置

| 产出 | 路径 | 写入时机 |
|------|------|----------|
| 汇总配置 | `<config 指定路径>`（UI 默认 `<设备根>\calibration_config.json`） | 0A/0B/0C 合格后 |
| 输出 JSON（显式） | `--output` 指定路径（UI 默认 `<输入同级>\output\<step>_output.json`） | 每次执行 |
| 归档-输入副本 | `<设备根>\device_info\<设备号>\<stepdir>\input\<step>_input_<时间戳>.json` | 提供 --device-root/-id 时 |
| 归档-输出成果 | `<设备根>\device_info\<设备号>\<stepdir>\output\<step>_output_<时间戳>.json` | 同上 |

`<stepdir>` 映射：`0A→camera_calibration`、`0B→mounting_calibration`、`0C→heading_calibration`、`0D→factory_verification`。

目录示例：

```
<设备根>/
  calibration_config.json
  device_info/
    AT1/
      camera_calibration/{input,output}/
      mounting_calibration/{input,output}/
      heading_calibration/{input,output}/
      factory_verification/{input,output}/   # 0D 放行报告与逐帧记录
```

## 6. 判据汇总（放行）

| 步骤 | 判据 |
|------|------|
| 0A | 重投影 RMS < 0.5 px |
| 0B | 各次 δ 偏差 ≤ 0.05° |
| 0C | ψ_offset 残差 < 0.1° |
| 0D | σ_rot < 0.3 mm 且 各方位闭合 < 0.5 mm（均值 < 0.3 mm） |

---

## 7. 样例

`samples/` 下提供 `0A_input.json`、`0B_input.json`、`0C_input.json`、`0D_input.json` 可直接运行验证：

```
CalibrationEngine.exe --step 0D --input samples\0D_input.json --output samples\0D_output.json
```
